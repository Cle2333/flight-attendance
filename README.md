# 航班打卡

一个纯本地的起飞打卡应用：双击屏幕记录一次起飞，所有数据保存在本机 SQLite 数据库中。

> 不联网、不登录、无排行榜、无云端同步。应用运行不依赖服务器。

## 功能

- **双击起飞**：记录当前时间、感受和起飞特效
- **日历记录**：按月浏览、按天查看，支持编辑时间和感受
- **实时倒计时**：修改任意记录时间后，立即按最新记录重算首页倒计时
- **快速统计**：总起飞次数、连续天数、平均起飞时间、徽章数量
- **每月报告**：
  - 本月起飞次数与上月环比
  - 有记录的天数
  - 最忙一天
  - 平均起飞时间（24 小时环形均值）
  - 每日起飞次数柱状图
- **徽章**：累计 1 / 10 / 50 / 100 次，以及最长连续 7 / 30 天
- **导入导出**：JSON 备份与 CSV 表格；导入按“起飞时间 + 感受”去重
- **旧数据迁移**：首次启动自动把旧版本地缓存迁入 SQLite，并清除历史 token / 服务器地址
- **主题与偏好**：昵称、头像、倒计时精度、起飞 emoji、机长语录、外观主题均本地持久化

## 技术栈

- Flutter + GetX
- SQLite：移动端 `sqflite`，Windows/Linux 使用 `sqflite_common_ffi`
- 文件导入导出：`file_selector`
- 无 HTTP 客户端、无认证状态、无后端目录

## 运行

```powershell
cd app
flutter pub get
flutter run -d windows
```

Android / iOS / macOS / Linux 也沿用 Flutter 常规运行方式。Web 不支持，本应用依赖本地 SQLite 文件。

## 数据与备份

数据位置可在「我的 → 本地 SQLite 数据库」查看。应用不会上传该文件。

- **JSON 备份**：完整记录字段，适合恢复和长期备份
- **CSV 表格**：适合查看和二次处理，导入时支持引号、逗号与换行备注
- **重复策略**：起飞时间（精确到秒）与感受完全相同视为重复，跳过不导入

> 建议定期导出 JSON 备份。卸载应用或清除应用数据会删除本地数据库。
